# じゃんけんゲーム（3回勝負）

HTML / CSS / JavaScript だけで動く、Safari向けのじゃんけんゲームです。
サーバーやビルドツールは不要で、`index.html` をSafariで開くだけで遊べます。

## 遊び方

1. Safariで `index.html` を開きます。
2. 「グー」「チョキ」「パー」のどれかのボタンを押します。
3. コンピューターの手と勝敗が表示されます。
4. 先に2勝したほうが、3回勝負の勝者です。
5. もう一度遊ぶ場合は「もう一度遊ぶ」ボタンを押します。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | GitHub Pagesで最初に表示されるゲーム画面です。 |
| `style.css` | 画面のデザイン、ボタン、スコア表示、スマートフォン対応の見た目を設定します。 |
| `script.js` | じゃんけんの勝敗判定、3回勝負のスコア管理、リセット処理を行います。 |
| `.nojekyll` | GitHub PagesでJekyll変換を使わず、静的ファイルをそのまま公開するための空ファイルです。 |

## ローカルで確認する方法

Safariでこのリポジトリ内の `index.html` を開いてください。

例:

```text
index.html を右クリック → このアプリケーションで開く → Safari
```

## GitHub Pagesで公開する手順

このリポジトリは、GitHub Pagesで公開できるようにリポジトリ直下に `index.html` を置いています。
以下の手順で公開できます。

1. GitHubでこのリポジトリを開きます。
2. 画面上部の **Settings** をクリックします。
3. 左側メニューの **Pages** をクリックします。
4. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
5. **Branch** で公開したいブランチ（例: `main`）を選び、フォルダーは **/ (root)** を選びます。
6. **Save** をクリックします。
7. 数十秒〜数分待つと、Pages画面に公開URLが表示されます。
8. 表示されたURLをSafariで開くと、じゃんけんゲームを遊べます。

公開URLは通常、次のような形式になります。

```text
https://<ユーザー名>.github.io/<リポジトリ名>/
```

## 更新した内容を公開ページに反映する方法

1. `index.html`、`style.css`、`script.js` を編集します。
2. 変更をGitHubにpushします。
3. GitHub Pagesが自動で再デプロイします。
4. 反映されない場合は、Safariでページを再読み込みしてください。
